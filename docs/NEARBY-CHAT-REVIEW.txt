Provider choices for a small controlled comparison, not a purchase recommendation
1. OpenAI GPT-5.4 mini: well-defined structured intent extraction, current documentation
   lists structured outputs support. Published standard prices: $0.75 input and $4.50
   output per million tokens.
2. Gemini 3.1 Flash-Lite: documented for high-volume translation and simple processing,
   with structured JSON output. Published standard prices: $0.25 input and $1.50 output

No five-language quality or latency winner is asserted without actual comparative tests.
Use the same Hebrew, English, Polish, German and Czech follow-up corpus before choosing.
For illustration only, 1,000 calls averaging 2,000 input and 400 billed output tokens
would be approximately $3.30 or $1.10 respectively at these prices. Actual input length,
reasoning/output billing, model availability, taxes and prices may differ. This is not
an account balance, a promise of free use, or a monetary spending cap.
The existing company ChatGPT membership is not evidence of API entitlement or credit.

Privacy and safeguards
Distance and radius inclusion are calculated locally. Model input contains the current
filters, at most 60 already displayed canonical IDs/names/rounded distances and the
user's current message. It excludes automatic device coordinates, customer accounts,
private maps, photographs and conversation logs. Users can still type sensitive data;
the interface asks them not to. No server prompt/response logging is implemented.
Provider retention and data-use terms require review for the actual account/tier.
OpenAI requests set store:false; this does not by itself assert zero provider retention.
No free-tier privacy or availability promise is made for Gemini.
The endpoint validates input/output, refuses unknown fields and invented result IDs,
restricts server-configured provider/model endpoints, has no redirect following,
uses a timeout, per-client hourly pseudonymous rate counters and a global daily request
limit. The counter charges every attempt, including failures, before the provider call.
Defaults in the disabled example: 12 calls/client/hour, 100 calls/day, at most 500 output
tokens per call. Rate limits are not a monetary cap; provider-side spending controls
must also be reviewed. No automatic provider fallback, model upgrade or retry billing.
The client invalidates stale results whenever the centre or filters change.
Changing the search centre to a referenced result requires an explicit dialog.
The server cannot attest device radius membership without device coordinates; the
browser independently validates references and re-runs canonical local search.
