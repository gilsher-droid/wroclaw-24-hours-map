# 24 שעות בוורוצלב

אפליקציית Web עצמאית וממותגת למסלול יום בוורוצלב, המבוססת על Leaflet ו־OpenStreetMap.

## קטלוג המוצרים

המפות מתפרסמות תחת `products/interactive-maps/`, כדי לאפשר לאתר להציע בעתיד מוצרים ושירותים נוספים לצד המפות:

- `products/interactive-maps/map.html` – מסלול 24 שעות.
- `products/interactive-maps/premium.html` – מסלול 4 ימים.
- `products/interactive-maps/moshe.html` – מסלול כריסמס.

הכתובות הישנות נשמרות כהפניות אוטומטיות, כדי שקישורים שכבר פורסמו ימשיכו לעבוד.

## מה כלול

- 14 תחנות במסלול המרכזי ועוד ארבע אפשרויות לערב.
- עברית, אנגלית ופולנית עם מעבר מיידי בין RTL ל־LTR.
- שמירת השפה האחרונה ופתיחה באמצעות `?lang=he`, `?lang=en` או `?lang=pl`.
- סינון תחנות, חלוניות מידע, קו מסלול וניווט חיצוני ב־Google Maps וב־Apple Maps.
- שיתוף באמצעות Web Share API או העתקת קישור.
- מצב הדפסה מותאם לשמירה כ־PDF.
- התאמה מלאה למסכי טלפון ולמקלדת.

## עדכון התחנות

כל התחנות נמצאות בקובץ `data/locations.js`. לכל תחנה יש מזהה, סדר, קואורדינטות, קטגוריה, שמות ותיאורים בשלוש שפות וזמן מומלץ. אפשר להזיז תחנה על ידי שינוי מערך `coordinates`, או לשנות את סדרה באמצעות `order`.

הקו הראשי מציג את התחנות שאינן מסומנות `optional`. זהו קו המחשה המחבר בין התחנות לפי הסדר, ולא מסלול ניווט מחושב.

## עדכון טקסטים ולוח זמנים

טקסטי הממשק, הטיפים ולוחות הזמנים נמצאים בקובץ `data/translations.js`. כל מפתח קיים בשלוש השפות.

## עדכון צבעים ולוגו

צבעי המותג מוגדרים בראש `styles.css` כמשתני CSS. ניתן להחליף את הלוגו באמצעות הקובץ `assets/logo.png`, בלי לשנות את הקוד.

## מקורות ובדיקת מיקומים

קואורדינטות התחנות הוצלבו מול OpenStreetMap, Wikidata, Wikimedia ופריטי מידע עירוניים. יש לבדוק סמוך לביקור שעות פתיחה וכרטיסים לאוניברסיטה, לאולה לאופולדינה, למגדל המתמטיקה, לקתדרלה ולמופעי הערב.
